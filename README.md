# 🎨 Thumbnail Maker

A browser-based thumbnail creation tool for creating eye-catching images for YouTube, TikTok, Shorts, Reels, and other social media platforms.

## ✨ Features

- 📷 Upload your own image
- ✏️ Add and edit text
- 🔤 Change text size and color
- ➡️ Add arrows
- ⭕ Add circles
- ▭ Add rectangles
- 😀 Add emojis
- 🎨 Change the background
- ☀️ Adjust brightness
- 🌓 Adjust contrast
- 🌈 Adjust saturation
- 🔍 Adjust blur
- ↩️ Undo and redo
- 📚 Manage layers
- 📋 Duplicate elements
- ⬆️ Move elements forward
- ⬇️ Move elements backward
- 🗑️ Delete elements
- 📱 Create different canvas sizes
- 💾 Export thumbnails as PNG or JPG

## 📐 Supported Formats

- YouTube Thumbnail — 1280 × 720
- TikTok / Shorts / Reels — 1080 × 1920
- Square — 1080 × 1080
- Portrait — 1080 × 1350
- Custom dimensions

## 🚀 How to Use

1. Upload an image.
2. Add text, arrows, shapes, or emojis.
3. Move the elements around the canvas.
4. Adjust the image appearance.
5. Choose your desired format.
6. Export your finished design.
